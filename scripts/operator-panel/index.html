Preparar una propuesta

Esta consulta no reserva una cohorte ni acredita a participantes. No muestra nóminas, identidades, recuentos ni medianas exactas.

Antes de acreditar a una persona

  1. Confirmar el permiso vigente para revisión interna y la cuenta a la que corresponde.
  2. Comprobar la vinculación de la persona con esa cuenta mediante una interacción directa acordada. El correo verificado por sí solo no basta.
  3. Revisar posibles cuentas duplicadas. Si existe duda, dejar el caso pendiente; no crear otra clave para la misma persona.
  4. Registrar únicamente una referencia de caso, la fecha, el resultado y el operador. No copiar documentos de identidad ni nóminas al expediente.
  5. Aplicar el procedimiento y el plazo de conservación aprobados antes de emitir una acreditación.

Preparación del piloto: las acreditaciones siguen cerradas hasta concretar el método de verificación y la conservación. Este panel no puede emitirlas.
